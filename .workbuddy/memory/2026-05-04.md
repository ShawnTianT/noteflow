# 2026-05-04 Noteflow 工作记录

## 修复手机端 JS 404 问题
- **根因**: `build.sh` 中的 sed 命令把 `../js/` 替换为 `./js/`，导致 mobile/index.html 中共享 JS（db-supabase.js 等）指向 mobile/js/（只有 app.js），404
- **修复**: 删除 build.sh 中的 sed 路径替换，共享 JS 文件保持 `../js/` 引用
- 同时修复 mobile/index.html 重复的 `</head>` 标签

## 修复标签连字符解析（v1.3.2）
- **问题**: `#复盘-周/小确幸` 被截断，因为标签正则 `\w` 不包含 `-`
- **修复**: 4处正则统一加 `-` → `[\w\u4e00-\u9fa5'-]+`
  - js/modules/editor.js extractTags()
  - js/modules/timeline.js highlightTags()
  - js/db-supabase.js extractTagsFromContent()
  - mobile/js/app.js extractTags() + highlightTags()

## PC端发布区改造为浮动按钮+弹窗（v1.3.2）
- 删除顶部固定的 editor-area，改为主区域右下角浮动按钮（fab-publish）
- 点击浮动按钮弹出发布弹窗（publish-modal），输入框、图片上传、标签预览在弹窗内
- 发送成功自动关闭弹窗，ESC 也可关闭
- 效果：信息流展示区域更大，不再被输入框挤压
